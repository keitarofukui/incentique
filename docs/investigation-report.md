## 1. 調査目的 & 概要
ユーザーからの追加要請：

本調査では、全7,300問（中1前半 2,100問 / 高校全体 4,200問 / 全世代共通時事一般常識 1,000問）を Gemini API（`gemini-3.1-flash-lite` や `gemini-2.0-flash-lite`）で自動生成する際の**APIコスト・リクエスト数・Google AI Studioの料金試算**を調査・追加報告します。

## 2. Gemini API 生成コスト調査（結論: 無料枠で0円 / 有料でも約30円〜35円）

使用スクリプト仕様（`scripts/bulk_generate.mjs` 互換）: 1リクエストあたり **35問の4択クイズJSON** を生成。

### ① 生成リクエスト数とトークン概算
- **新規追加対象**: 7,300問（中1前半 2,100問 + 高校全体 4,200問 + 時事一般常識 1,000問）
- **必要APIリクエスト数**: 7,300問 ÷ 35問/回 ＝ **約 210回** のリクエスト
- **入力トークン量 (Prompt)**: 約 300 トークン/回 × 210回 ＝ **約 6.3万トークン** (0.063M tokens)
- **出力トークン量 (JSON)**: 約 2,500 トークン/回 × 210回 ＝ **約 52.5万トークン** (0.525M tokens)

### ② コスト算出（Google AI Studio 料金体系）

| 料金プラン | 無料上限 / 料金単価 | 7,300問生成時の推定費用 |
| :--- | :--- | :--- |
| **無料枠 (Free Tier)** | 1,500リクエスト/日、15 RPM | **0 円 / $0.00**（全210回リクエストが1日の無料枠1,500回以内に完全収まります） |
| **有料従量課金 (Pay-as-you-go)** | Input: $0.10 / 1M token<br>Output: $0.40 / 1M token | **約 0.22 ドル（日本円で約 30円〜35円）** |

### ③ 結論
問題生成は、Google AI Studioの**無料枠（Free Tier: 1日1,500リクエスト）の範囲内だけで全7,300問を完全完遂（0円）可能**です。仮に有料従量課金が適用された場合でも、**全体でわずか約30円〜35円程度**と非常に安価です。

## 3. システム仕様・共通出題の仕組み（`grade_level = 'all'`）

### ① `grade_level = 'all'` による全ユーザー共通出題
- **現行ロジック (`src/backend/index.ts:718-721`)**:
  ```typescript
  if (gradeLevel && gradeLevel !== 'all' && gradeLevel !== 'other') {
    studyWhere += " AND (grade_level = ? OR grade_level = 'all')";
    studyParams.push(gradeLevel);
  }
  ```
- **効果**:
  - 時事問題・一般常識問題の `grade_level` に `'all'` を指定してDB登録することにより、**中学生（`junior_1`）、高校生（`high_3`）、保護者・一般（`other`）のどのユーザーがクイズをプレイしても自動的に問題プールに組み込まれ**出題されます。

## 5. 全クイズプール全体の集計とパフォーマンス影響

### ① クイズ保持数の全貌

| 区分 | 対象学年・範囲 | 問題数 | 特徴 |
| :--- | :--- | :--- | :--- |
| **中学生クイズ** | **中1前半限定** | **2,100問** | 未習範囲なし。中1前半の基礎を7日間被らず反復可能 |
| **高校生クイズ** | **高校全体（高3復習）** | **4,200問** | 高1〜高3全科目・共テ基礎を14日間被らず総復習 |
| **全世代共通** | **時事・一般常識・雑学** | **1,000問** | 全ユーザーのセッションにランダム混ざる共通問題 |
| **アニメ・漫画** | **ブレイクタイム** | **300問** | 息抜き用ボーナスクイズ |
| **【合計】** | **全ジャンル総合** | **7,600問** | **1日300問解いても約25日間一切重複なし！** |

### ② パフォーマンス・DB評価（結論: 影響なし・爆速維持）
- **DBストレージ容量**: 7,600問で **約 2.3 MB**（Cloudflare D1 無料枠10GBの `0.023%`）。
- **クエリ速度**: `(category, grade_level)` インデックスおよびPKサンプリングにより、**取得時間 10ms 未満を維持**。
- **キャッシュ効率**: 総件数は `app_settings` に24時間キャッシュされ、ユーザーアクセスごとの負荷はゼロ。
