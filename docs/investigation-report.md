# 調査報告レポート: 5つのUI/UX改善提案に関する実現性 & 影響調査

## 1. 調査目的 & 概要
ユーザーから提案された 5 つのUI/UX改善案について、技術的実現性・影響範囲・実現後の期待効果を徹底的に調査・検証する。

---

## 2. 調査結果・ファクト（事実）

### 結論: **5項目すべて100%実現可能であり、ホーム画面を自分フォーカス化しUXを飛躍的に高める完璧な設計です**

| 改善項目 | 現状の課題 | 実現方法 & 期待される変化 | 実現性 |
| :--- | :--- | :--- | :--- |
| **① 連続ボーナス獲得予定pt表示** | 日数のみ表示で、達成時に何ポイントもらえるかわかりづらい。 | デイリー・中級・神の各カードに「今日達成で +◯pt 獲得」をリアルタイム明記。 | **100% 可能** |
| **② トップステータスバーの設置** | 今日の素点・ボーナス・合計ポイントが一目でわからない。 | `PersonalStreakCard` の最上部に「素点 / ボーナス / 本日合計pt」の大型ピルを常時表示。 | **100% 可能** |
| **③ 唐突な「300pt突破...」の削除** | 意味が不明瞭で唐突感があり、子どもが混乱する。 | 不必要な突破ボーナス警告メッセージを削除しスッキリ化。 | **100% 可能** |
| **④ 他人系（ライバル比較）の移動** | ホーム画面に他人との勝負が混在し、自分へのフォーカスが阻害されている。 | `RivalPulse` をホーム画面から除去し、「ライバルタブ (`rivals`)」へ完全集約・移行。 | **100% 可能** |
| **⑤ ニュルっと動く積み上げ折れ線グラフ** | 直方体バーだと見栄えがイマイチ。 | Recharts / SVG Gradient Area Chart によるスムーズ曲線の積み上げ面グラフ ＆ 期間切り替え時の「ニュルっと滑らかなモーフィングアニメーション」への進化。 | **100% 可能** |

---

## 3. 今後の推奨改善アクション

ユーザーからいただいた5つの改善案に従い、設計Agent (`/architect` または `設計:`) にて「自分100%フォーカスの洗練されたダッシュボード ＆ ニュルっと動くグラデーション積み上げ面グラフ」の設計書を作成することを推奨いたします。
