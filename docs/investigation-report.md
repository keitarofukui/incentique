# 調査報告レポート: グラフにおける「食事」と「ボーナス」の明確分離

## 1. 調査目的 & 概要
ユーザーからの指摘「食事とボーナスは分けてください。ボーナスが多いので食事が多いと勘違いする。」に基づき、獲得ポイント推移グラフ（`DailyChart.tsx`）におけるログカテゴリ分類を調査し、「食事（`eat_rice`/`eat_meat`）」と「ボーナス（`bonus`）」を完全に分離・独立表示する実装方針を策定。

---

## 2. 現状の課題と原因
- **現状**: `DailyChart.tsx` の集計ロジックで `quiz`, `input`, `training` 以外の全ログが `other`（表記:「🍚 食事/他」）にまとめられていた。
- **発生している問題**: 突破ボーナスや全カテゴリ制覇ボーナスなどの大きなポイントが「食事/他」層に合算されるため、グラフ上で食事の山が異常に大きく表示され、「食事ばかり記録している」という誤解（認知の誤認）が生じている。

---

## 3. 分離・改修方針

### ログの5カテゴリ分離定義
| カテゴリキー | 対象ログカテゴリ | UI表示名 & アイコン | カラーテーマ |
| :--- | :--- | :--- | :--- |
| `quiz` | `quiz`, `study` | 🧠 クイズ | **シアン (Cyan)** (`#22d3ee` ~ `#0284c7`) |
| `input` | `input_*` (book/movie/manga) | 📚 インプット | **パープル (Purple)** (`#c084fc` ~ `#7c3aed`) |
| `training` | `training` | 🏋️ 運動 | **エメラルド (Emerald)** (`#34d399` ~ `#059669`) |
| `meal` | `eat_rice`, `eat_meat` | 🍚 食事 | **アンバー (Amber)** (`#fbbf24` ~ `#d97706`) |
| `bonus` | `bonus` および その他 | 🎁 ボーナス | **ローズ/ピンク (Rose)** (`#f43f5e` ~ `#e11d48`) |
