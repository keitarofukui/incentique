## 3. 指摘事項 & 改善提案
1. **[UI/UX] 0円または負の金額入力時のガード**
   - 換金希望金額に 0 以下の数値が入力された場合や空文字の場合、`requiredPointsForCash` は 0 にし、登録ボタンを非活性（または「1円以上の金額を入力してください」アラート）にする制御を確認してください。
2. **[計算精度] 切り上げ計算の確認**
   - `Math.ceil(cashAmount / 0.7)` は正確です（例: 700円 $\rightarrow$ 1,000pt, 500円 $\rightarrow$ 715pt）。所持ポイントと残りポイントの表示も統一されたフォント（`font-mono`）で視認性を高く保ってください。
