## 2. 内容妥当性レビュー
- **要件網羅性**: ユーザー要望の「中1前期/後期」「中2前期/後期」「中3前期/後期」「高校」の7区分が漏れなく網羅されている。
- **操作性・誤動作防止**: `.no-swipe` クラスに加え、スクロールコンテナでの `onTouchStart={(e) => e.stopPropagation()}` を設計しており、横スワイプによるタブ誤遷移が確実に防止される。
