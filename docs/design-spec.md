# 機能設計仕様書: ライバルタブカード適正整理 ＆ カテゴリ別積み上げ推移グラフ UI

## 1. 概要・目的
ユーザーフィードバックに基づき、以下の2点を改善する：
1. **ライバルタブのカード混入の適正整理**: ライバルタブ内に紛れ込んでいた「個人の当日獲得ポイント内訳（素点・ボーナス）」および「全カテゴリ制覇」カードを他者比較コンポーネント（`RivalPulse.tsx`）から切り離し、自分専用のホーム画面（`Dashboard.tsx`）へ適正に配置・統合する。ライバルタブは純粋な「他者ランキング・勝負」に特化させる。
2. **推移グラフのカテゴリ別積み上げ可視化 (`DailyChart.tsx`)**: 単一合計のみだった推移グラフを、カテゴリ別（クイズ、インプット、運動、その他）の層（レイヤー）に分けた「**カテゴリ別積み上げ面グラデーション（Stacked Area Chart）**」に進化させ、どのカテゴリをどれくらい頑張っているのか一目で視覚化できるようにする。

---

## 2. 改修仕様の詳細

### 2.1 ライバルタブ ＆ ホーム画面のカード整理 (`RivalPulse.tsx`, `Dashboard.tsx`, `App.tsx`)
1. **`RivalPulse.tsx` のスリム化（他者比較専用化）**:
   - 「自分の今日の素点・ボーナス内訳（および突破ボーナス）」および「全カテゴリ制覇」カードを `RivalPulse.tsx` 内から除去。
   - `RivalPulse.tsx` は「⚔️ 今日の勝負（他者との本日の順位・獲得pt比較）」と「🏆 今週のチャンピオン（カテゴリ別王冠）」のみを表示する純粋な他者比較コンポーネントに再構成。
2. **ホーム画面 (`Dashboard.tsx`) への「全カテゴリ制覇」カードの統合**:
   - 自分専用のコンポーネントとして `Dashboard.tsx` の上部（`PersonalStreakCard` の下など）に「🎯 全カテゴリ制覇」カードを新設・配置。
   - 自分の本日の達成状況（クイズ・インプット・運動・食事の4カテゴリ）と、あとどのカテゴリをやればボーナスがもらえるかをわかりやすく提示する。

### 2.2 カテゴリ別積み上げ推移グラフ (`DailyChart.tsx`)
1. **カテゴリ別データ構造化**:
   - 日別の集計データを `quiz` (クイズ/学習), `input` (インプット/読書・映画), `training` (運動), `other` (食事/ボーナス等) の4カテゴリに明確に分類。
2. **カテゴリ別積み上げSVG描画 (Stacked Area Layers)**:
   - 各日付における累積高さ `y0` (下端), `y1` (上端) を計算し、カテゴリごとに積み上げたSVG面（Area Path）を描画。
   - 各カテゴリに応じた魅力的なネオングラデーションとカラーを割り当て：
     - 🧠 クイズ: ネオンシアン (`#06b6d4` ~ `#3b82f6`)
     - 📚 インプット: ネオンパープル/インディゴ (`#8b5cf6` ~ `#6366f1`)
     - 🏋️ 運動: ネオンオレンジ/ローズ (`#f97316` ~ `#f43f5e`)
     - 🍚 食事/その他: ネオンエメラルド (`#10b981` ~ `#059669`)
3. **グラフ凡例 (Legend) & 詳細ツールチップ**:
   - グラフ上部または下部にカテゴリ別カラー凡例を表示。
   - データポイントホバー時、合計ポイントだけでなく「🧠 クイズ: +X pt」「📚 インプット: +Y pt」「🏋️ 運動: +Z pt」「🍚 食事/他: +W pt」の内訳をポップアップで表示。
