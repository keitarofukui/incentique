# 機能設計仕様書: 自分100%フォーカスホーム画面 ＆ ニュルっと動く積み上げ面グラデーショングラフUI

## 1. 概要・目的
ホーム画面（ダッシュボード）を**100%自分自身にフォーカスした空間**へ昇華させる。他人比較コンポーネントをライバルタブへ完全移行し、メインカード最上部へ「素点・ボーナス・本日合計pt」のトップステータスバーと「今日達成時の想定獲得pt」を明記。さらに、ポイント推移グラフを**ニュルっと動くネオングラデーション積み上げ面グラフ (Smoothed Gradient Area Chart)** へ大幅進化させる。

---

## 2. 改修仕様の詳細

### 2.1 メインダッシュボードカード (`PersonalStreakCard.tsx`)
1. **トップステータスバー (新規設置)**:
   - 「今日の成果サマリー」ピル: `素点: ◯pt` ＋ `ボーナス: ◯pt` ＝ `本日合計: ◯pt` を大型バッジで最上部に常時表示。
2. **今日達成時の獲得想定ptのリアルタイム案内**:
   - ① デイリー連続: `今日達成で +{(streakDaily + 1) * dailyMultiplier} pt`
   - ② 中級連続: `今日達成で +{(streakMid + 1) * midMultiplier} pt`
   - ③ 神連続: `今日達成で +{(streakGod + 1) * godMultiplier} pt`
3. **不要・混乱テキストの削除**:
   - 唐突感のあった「次の300ポイント突破...」などの固定警告テキストを排除し、デザインをスッキリ化。

---

### 2.2 ホーム画面の自分100%フォーカス化 (`Dashboard.tsx` & `App.tsx`)
1. **ホーム画面 (`Dashboard.tsx`) から `RivalPulse` (他人比較) を除去**:
   - 他人の行動や「今日の勝負」「今週のチャンピオン」をホームから切り離し、自分の記録・グラフ・タイムラインのみの集中環境へ整理。
2. **ライバルタブ (`RivalBoard.tsx` / `activeTab === 'rivals'`) への集約**:
   - 他人比較コンポーネント (`RivalPulse`) は「ライバルタブ」内へ配置し、ライバルとの対戦・ランキングを見たい時だけアクセスする構造に変更。

---

### 2.3 ニュルっと動く積み上げ面グラデーショングラフ (`DailyChart.tsx`)
1. **積み上げ面グラフ (Smoothed Gradient Area Chart) への進化**:
   - SVG Smooth Area Curve（ネオンシアン / ローズ / インディゴのグラデーション塗りと美しいグラデーションライン）を導入。
2. **3期間切替 ＆ ニュルっとモーフィングアニメーション**:
   - `[ 7日 ]` `[ 30日 ]` `[ 90日 ]` ネオントグルボタン。
   - タブ切り替え時に SVG パスとデータポイント、および合計・平均値が `transition-all duration-500 ease-out` で「ニュルっと滑らかに波形伸縮」するアニメーション演出。
