# 機能設計仕様書: 連続ボーナス（マイルストーン・到達閾値）の保護者ポータル管理画面設定化

## 1. 概要・目的
連続ボーナスのマイルストーン日数（節目）、各段階（中間・神ボーナス）の素点達成閾値、および獲得ポイント係数を、保護者ポータル（管理画面）から自由かつ柔軟に変更できるように拡張する。

---

## 2. 機能要件 & データ構造

### 2.1 `point_rules` マスターテーブルの拡張項目
バックエンドの `GET /api/point-rules` 呼び出し時に、以下の設定キーが存在しない場合、デフォルト値として自動初期挿入 (INSERT OR IGNORE) を行う。

| カテゴリキー (`category`) | タイトル (`title`) | ポイント/設定値 (`points`) | 初期値 / 型 | 説明 (`description`) |
| :--- | :--- | :--- | :--- | :--- |
| `streak_milestones` | 連続ボーナス節目日数 | `0` (文字項目) | `"2,3,4,5,6,7,10,14,21,30,50,100,150,200,250,300,365"` | ボーナスが発生する節目日数（カンマ区切り） |
| `streak_daily_multiplier` | デイリー連続ボーナス係数 | `10` | `10` (数値) | デイリー連続達成時の1日あたり獲得ポイント (日数 × 係数) |
| `streak_mid_threshold` | 中級連続ボーナス達成閾値 | `100` | `100` (数値) | 中級連続ボーナス判定に必要な1日の素点 (pt) |
| `streak_mid_multiplier` | 中級連続ボーナス係数 | `30` | `30` (数値) | 中級連続達成時の1日あたり獲得ポイント (日数 × 係数) |
| `streak_god_threshold` | 神連続ボーナス達成閾値 | `250` | `250` (数値) | 神連続ボーナス判定に必要な1日の素点 (pt) |
| `streak_god_multiplier` | 神連続ボーナス係数 | `100` | `100` (数値) | 神連続達成時の1日あたり獲得ポイント (日数 × 係数) |

※ 文字列保存が必要な `streak_milestones` に対応するため、`point_rules` テーブルに `value_text` (TEXT) カラムを必要に応じて追加/活用、または `description` / 特殊フィールドで相互互換を保つ。

---

### 2.2 バックエンド処理ロジック仕様 (`src/backend/index.ts`)

`updateStreaks` 関数内で、ハードコードされていた定数を DB から読み込んだ動的設定値へ置き換える：

1. **`point_rules` からのルール取得**:
   - `SELECT category, points, description FROM point_rules` を取得。
2. **動的パラメータの解析**:
   - `STREAK_MILESTONES`: DB内の `streak_milestones` のカンマ区切り文字列（例: `"2,3,4,5,6,7,10,14,21..."`）を `split(',')` して数値配列 `number[]` に変換。
   - 各閾値・係数: DB の設定値を参照（未設定時はデフォルト値フォールバック）。
3. **ストリーク判定・差額給付の適用**:
   - 取得した動的閾値（`streak_mid_threshold`, `streak_god_threshold`）および動的係数（`streak_daily_multiplier`, `streak_mid_multiplier`, `streak_god_multiplier`）に基づいて、満額ボーナスを算出し差額を給付。

## 3. UI / コンポーネント設計 (`src/frontend/components/ParentPortal.tsx`)

保護者ポータルの「ポイント獲得ルールの設定・変更」タブ（`activeSubTab === 'point_rules'`）内に以下の管理カードUIを追加する：

1. **連続ボーナス詳細設定カード (特製管理UI)**:
   - **マイルストーン日数設定**:
     - テキスト入力フィールド (例: `2, 3, 4, 5, 6, 7, 10, 14, 21, 30, 50, 100`)
     - ヘルプ注記：「カンマ区切りでボーナスをあげたい日数を指定できます」
   - **3段階ストリークの閾値・係数設定グリッド**:
     - デイリー連続係数 (pt/日)
     - 中級連続素点閾値 (pt) & 係数 (pt/日)
     - 神連続素点閾値 (pt) & 係数 (pt/日)
2. **保存アクション**:
   - 変更後に「保存」ボタンを押すことで、既存の `PUT /api/point-rules` 経由で即座にデータベースに反映される。
