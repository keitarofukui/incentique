# 機能設計仕様書: ホーム画面抜本再編 ＆ 動的アニメーション付きマルチ期間推移グラフUI

## 1. 概要・目的
ホーム画面（ダッシュボード）の構成を洗練された4段構成へ抜本再編し、ポイント推移グラフ (`DailyChart.tsx`) において **[ 7日 ] [ 30日 ] [ 90日 ] の期間切り替え時にグラフが滑らかに動くスタイリッシュな動的アニメーション・インタラクションUI** を設計・実現する。

---

## 2. ホーム画面全体の構成 (`src/frontend/App.tsx` & `Dashboard.tsx`)

ホーム画面は以下の 4 ブロック構成へ統合再編します：

```
+-----------------------------------------------------------------------+
| 1. メインダッシュボードカード (PersonalStreakCard)                     |
|    - 3段階の連続記録 (デイリー/中級/神) ＆ 本日素点残りptナビ            |
|    - 全カテゴリ制覇状況 (4カテゴリ達成バッジ ＆ 残りカテゴリ案内)       |
+-----------------------------------------------------------------------+
| 2. 今週のライバルたち (RivalPulse)                                    |
|    - ライバル比較・本日の記録状況・週間王冠 (重複連続ブロック削除済)     |
+-----------------------------------------------------------------------+
| 3. ポイント獲得推移グラフ (DailyChart - 3期間動的アニメーション対応)   |
|    - 期間切替タブ: [ 7日間 ]  [ 30日間 ]  [ 90日間 ]                  |
|    - 期間変更時にグラフ高さ・軸・平均値が滑らかに展開アニメーション    |
+-----------------------------------------------------------------------+
| 4. 主な活動成果ログタイムライン (Recent Activity)                      |
+-----------------------------------------------------------------------+
```

※「目標設定 (`GoalPlannerWidget`)」はホーム画面のメインストリームから取り外し、別画面（個人設定/マイページ等）へ整理移動します。

---

## 3. 各コンポーネントの改修仕様

### 3.1 メインダッシュボードカード (`PersonalStreakCard.tsx` の拡張)
- **連続記録エリア**: 自分専用の 3 段階ストリーク（①デイリー / ②中級 / ③神）、本日素点進捗バー、残りpt案内。
- **全カテゴリ制覇エリア (統合)**:
  - 4つのカテゴリ（`クイズ/勉強`, `運動`, `食事/水分`, `読書/インプット`）の本日達成アイコン。
  - 制覇状況（例: `🎉 全4カテゴリ制覇！ (+100pt獲得)` / `あと【運動】を記録すると制覇！`）。

### 3.2 今週のライバルたち (`RivalPulse.tsx` の整理)
- 二重表示となっていた内部の「連続記録」ブロックを削除。
- ライバルとの「対戦・週間王冠・本日記録有無」に特化したスッキリしたカードとして整理。

### 3.3 動的アニメーション付き推移グラフ (`DailyChart.tsx` の進化)
- **期間切替タブ**: `[ 7日 ]` `[ 30日 ]` `[ 90日 ]` のトグルスイッチ（ネオンカラーアクティブ表示）。
- **期間に応じたデータ集計**:
  - `7日` モード: 過去7日間の日別積み上げバー ＆ 日平均・合計。
  - `30日` モード: 過去30日間のポイント高低推移バー（7日移動平均線つき） ＆ 30日合計。
  - `90日` モード: 過去90日間のポイントトレンド ＆ 90日合計。
- **かっこいい動的アニメーション (`transition-all duration-500 ease-out`)**:
  - 期間切り替え時に、各バーの高さやスケール、移動平均インジケーター、合計・平均値の数字がヌルヌルと滑らかにスライド・伸縮アニメーションする演出を実装。
